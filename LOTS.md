# Découpage en lots

Chaque lot = 1 étape livrable = 1 commit + 1 push.

| Lot | Contenu | Message de commit |
|-----|---------|-------------------|
| **Lot 0** | Squelette : README, SPEC, LOTS, page vide avec titre | `Lot 0 : squelette du projet` |
| **Lot 1** | Formulaire d'ajout + liste simple des publications | `Lot 1 : ajout de publications` |
| **Lot 2** | Vue calendrier du mois + navigation mois précédent/suivant | `Lot 2 : vue calendrier` |
| **Lot 3** | Changer le statut, supprimer, filtres réseau/statut | `Lot 3 : statuts, suppression, filtres` |
| **Lot 4** | Sauvegarde (localStorage) + compteurs + design final | `Lot 4 : sauvegarde et design` |

## Où se fait chaque lot
- Lot 0 → créé avec Claude, poussé sur GitHub depuis ta machine.
- Lots 1 à 4 → développés dans Replit, poussés sur GitHub depuis Replit.
- À la fin → `git pull` sur ta machine pour récupérer la version finale.
